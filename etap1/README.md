# Этап 1 — числа и словари

## Что уже умеет программа

- читает конфигурацию из файла (первый аргумент командной строки);
- понимает числа `\d+` и словари `$[ ИМЯ : значение, ... ]`;
- поддерживает вложенные словари любой глубины;
- находит повторы имён и синтаксические ошибки (строка и столбец);
- пишет результат в формате TOML во второй файл-аргумент.

Разбор текста выполняет библиотека **lark** — специализированный
инструмент синтаксического разбора (требование задания).

## Структура этапа

| Файл | Назначение |
|---|---|
| `main.py` | весь код этапа (единый файл) |
| `test_main.py` | модульные тесты (unittest) |
| `run.bat` / `run.sh` | запуск программы и тестов (Windows / Linux) |

## Как запустить (Windows)

1. Нужен Python 3.10+ и библиотека: `pip install lark`
2. `run.bat input.cfg output.toml` — из консоли.
   Без аргументов программа покажет подсказку и не закроется
   (окно ждёт нажатия клавиши).

## Как запустить (Linux)

1. `python3 -m pip install lark`
2. `sh run.sh input.cfg output.toml`

## Как запустить тесты

- Windows: `run.bat test`
- Linux: `sh run.sh test`

## Пример

Вход `in.cfg`:

```
$[PORT: 80, SERVER: $[NAME: 1]]
```

Команда: `run.bat in.cfg out.toml`

Выход `out.toml`:

```
PORT = 80
[SERVER]
NAME = 1
```

## Пример ошибки

Вход `$[PORT: 80` (без закрывающей скобки) — программа напечатает
сообщение с номером строки и фрагментом текста, вернёт код 1.
