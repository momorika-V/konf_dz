# Этап 3 — константы (этапы 1, 2 + новые возможности)

## Что уже умеет программа

Всё из этапов 1 и 2 (числа, словари, комментарии, ошибки) плюс:

- объявление константы на этапе трансляции: `var ИМЯ = значение;`
- константой может быть число или словарь;
- повторное объявление той же константы — ошибка;
- константы в итоговый TOML не попадают (они для вычислений,
  которые появятся на этапе 4).

## Структура этапа

| Файл | Назначение |
|---|---|
| `main.py` | весь код этапов 1–3 (единый файл) |
| `test_main.py` | модульные тесты (unittest) |
| `run.bat` / `run.sh` | запуск программы и тестов (Windows / Linux) |

## Как запустить (Windows)

1. Нужен Python 3.10+ и библиотека: `pip install lark`
2. `run.bat input.cfg output.toml`

## Как запустить (Linux)

1. `python3 -m pip install lark`
2. `sh run.sh input.cfg output.toml`

## Как запустить тесты

- Windows: `run.bat test`
- Linux: `sh run.sh test`

## Пример

Вход `in.cfg`:

```
// Базовый порт для вычислений
var BASE = 8000;

$[PORT: 80]
```

Команда: `run.bat in.cfg out.toml`

Выход `out.toml` (константа BASE в вывод не попала):

```
PORT = 80
```

## Пример ошибки

Вход `var BASE = 1; var BASE = 2;` — программа сообщит:
«Константа BASE объявлена дважды».
