# Этап 4 — константные выражения (этапы 1–3 + новые возможности)

## Что уже умеет программа

Всё из этапов 1–3 плюс вычисление константных выражений на этапе
трансляции в префиксной форме:

```
|операция операнд операнд|
```

| Запись | Смысл | Результат |
|---|---|---|
| `\|+ A B\|` | сложение | `A + B` |
| `\|- A B\|` | вычитание | `A - B` |
| `\|* A B\|` | умножение | `A * B` |
| `\|max A B\|` | максимум | большее из A и B |
| `\|pow A B\|` | степень | `A ** B` |

Операндом может быть число, имя константы или другое выражение
(вложенность любой глубины): `|+ |* 2 3| 1|` = 7.

Ошибки: константа не объявлена, объявлена позже использования,
константа-словарь в арифметике, отрицательная степень в `pow`.

## Структура этапа

| Файл | Назначение |
|---|---|
| `main.py` | весь код этапов 1–4 (единый файл) |
| `test_main.py` | модульные тесты (unittest) |
| `run.bat` / `run.sh` | запуск программы и тестов (Windows / Linux) |

## Как запустить (Windows)

1. Нужен Python 3.10+ и библиотека: `pip install lark`
2. `run.bat input.cfg output.toml`

## Как запустить (Linux)

1. `python3 -m pip install lark`
2. `sh run.sh input.cfg output.toml`

## Как запустить тесты

- Windows: `run.bat test`
- Linux: `sh run.sh test`

## Пример

Вход `in.cfg`:

```
var BASE = 8000;

$[
  PORT: |+ BASE 80|,
  SIZE: |pow 2 10|,
  LOGS: $[LEVEL: |max 1 3|]
]
```

Команда: `run.bat in.cfg out.toml`

Выход `out.toml`:

```
PORT = 8080
SIZE = 1024
[LOGS]
LEVEL = 3
```
