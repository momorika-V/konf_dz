# Этап 5 — финальная версия (весь синтаксис варианта 22)

## Что умеет программа

Весь синтаксис варианта 22:

- числа `\d+`, имена `[A-Z]+`;
- словари `$[ ИМЯ : значение, ... ]` с любой вложенностью;
- однострочные комментарии `// текст`;
- многострочные комментарии `(comment текст )`;
- константы `var ИМЯ = значение;`;
- константные выражения в префиксной форме `|+ ИМЯ 1|`
  с операциями `+`, `-`, `*`, `max()`, `pow()`.

Плюс два режима работы:

1. **Режим аргументов** (по заданию):
   `python main.py вход.cfg выход.toml`
2. **Диалоговый режим** (удобство): `run.bat` без аргументов —
   программа сама спрашивает пути, повторяет запрос при ошибке,
   выходит по команде `q` и не закрывает окно сама.

Обработка ошибок: файл не найден, указана папка, не UTF-8, нельзя
записать результат, синтаксическая ошибка (строка и столбец),
повторы имён, необъявленные константы, отрицательная степень.

## Структура этапа

| Файл | Назначение |
|---|---|
| `main.py` | весь код этапов 1–5 (единый файл) |
| `test_main.py` | модульные тесты (unittest) |
| `run.bat` / `run.sh` | запуск программы и тестов (Windows / Linux) |

## Как запустить (Windows)

1. Нужен Python 3.10+ и библиотека: `pip install lark`
2. `run.bat input.cfg output.toml` — из консоли,
   либо двойной клик по `run.bat` для диалогового режима.

## Как запустить (Linux)

1. `python3 -m pip install lark`
2. `sh run.sh input.cfg output.toml`

## Как запустить тесты

- Windows: `run.bat test`
- Linux: `sh run.sh test`

## Пример

Вход `in.cfg`:

```
var BASE = 8000;

$[
  PORT: |+ BASE 80|,
  LOGS: $[SIZE: |pow 2 20|]
]
```

Команда: `run.bat in.cfg out.toml`

Выход `out.toml`:

```
PORT = 8080
[LOGS]
SIZE = 1048576
```
