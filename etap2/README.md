# Этап 2 — комментарии (этап 1 + новые возможности)

## Что уже умеет программа

Всё из этапа 1 (числа `\d+`, словари `$[ ... ]`, вложенность,
проверка ошибок) плюс:

- однострочные комментарии: `// текст` — до конца строки;
- многострочные комментарии: `(comment текст )` — через любое
  число строк, в том числе внутри словарей;
- понятное сообщение, если многострочный комментарий не закрыт.

## Структура этапа

| Файл | Назначение |
|---|---|
| `main.py` | весь код этапов 1 и 2 (единый файл) |
| `test_main.py` | модульные тесты (unittest) |
| `run.bat` / `run.sh` | запуск программы и тестов (Windows / Linux) |

## Как запустить (Windows)

1. Нужен Python 3.10+ и библиотека: `pip install lark`
2. `run.bat input.cfg output.toml`

## Как запустить (Linux)

1. `python3 -m pip install lark`
2. `sh run.sh input.cfg output.toml`

## Как запустить тесты

- Windows: `run.bat test`
- Linux: `sh run.sh test`

## Пример

Вход `in.cfg`:

```
// Настройки сервера
(comment
  комментарий через несколько строк
)
$[
  PORT: 80, // порт
  LOGS: $[LEVEL: 1]
]
```

Команда: `run.bat in.cfg out.toml`

Выход `out.toml`:

```
PORT = 80
[LOGS]
LEVEL = 1
```
